# 🚀 CareerNavigator Bot (Demo)

Демо-версия Telegram-бота для подбора карьеры и профориентации подростков и специалистов, желающих сменить сферу деятельности. Проект разработан в рамках тестирования функционала для стартапа.

---

## 📌 Описание проекта

**CareerNavigator** — это интерактивный Telegram-бот, который анализирует интересы, навыка и предпочтения пользователя и выдаёт персонализированные рекомендации по профессиям, обучению и первым шагам в карьере.

### 🔥 Ключевые возможности:
* **Адаптивность и персонализация:** Опросник делится на два трека — **«Подросток / Старт»** и **«Смена профессии (Свитчинг)»**.
* **Гибридный интерфейс:** Интерактивные `Inline` и `Reply` кнопки + обработка свободных текстовых запросов.
* **Понятный формат:** Короткие, структурированные карточки профессий с курсовой навигацией, средней зарплатой и треками развития.
* **Динамическая База Данных:** Легко расширяемая система на SQLite.

---

## 🛠 Технологический стек

* **Язык:** Python 3.10+
* **Библиотека Telegram:** `aiogram 3.x` (или `disnake`/`discord.py` при адаптации)
* **База данных:** SQLite3 + `aiosqlite`
* **Форматирование:** HTML / MarkdownV2

---

## 🗄 Структура Базы Данных и формат наполнения

База данных SQLite включает 3 основные таблицы. 

### 1. Таблица `careers` (Профессии)

| Поле | Тип | Описание |
| :--- | :--- | :--- |
| `id` | INTEGER PRIMARY KEY | Уникальный ID |
| `title` | TEXT | Название профессии |
| `category` | TEXT | Категория (`IT`, `Design`, `Marketing`, `Management`, etc.) |
| `target_audience` | TEXT | `teen` (подростки), `adult` (свитчеры), `all` (для всех) |
| `description` | TEXT | Краткое описание профессии понятным языком |
| `skills_required` | TEXT | Требуемые ключевые навыки (через запятую) |
| `avg_salary` | TEXT | Примерный уровень дохода / вилка |
| `first_steps` | TEXT | Первые 3 шага для старта в этой сфере |
