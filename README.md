# 🧭 CareerNavigator Bot

Telegram-бот для подбора карьеры и профориентации.

Проект под ТЗ стартапа: бот помогает **подросткам** и **людям, уставшим от текущей работы**, найти новые интересные пути для развития. Задаёт пару вопросов и выдаёт персональную подборку профессий с зарплатой и первыми шагами.

---

## 📌 Идея

Пользователь нажимает «Подобрать профессию» → бот спрашивает, **кто он** (новичок/подросток или свитчер) и **какая сфера** интересна (IT, Дизайн, Менеджмент) → выдаёт подходящие профессии в виде понятных карточек. Выдача зависит от ответов, поэтому подростку и взрослому по одной и той же сфере прилетят **разные** варианты.

## 🔍 Референсы

Смотрел для вдохновения, как делают подобное:

* **@career_guide_bot, @proforientator_bot** — боты-профориентаторы: формат «вопрос → подборка».
* **HeadHunter / «Профориентация» от ВУЗов** — какие поля важны в карточке профессии (навыки, зарплата, рост).
* **Документация aiogram 3.x** — FSM (машина состояний) и работа с Inline-кнопками.
* **Квиз-боты** — идея вести пользователя по шагам, а не грузить всё сразу.

| 1 | Персональные рекомендации под разные запросы | Два трека (подросток / свитчер) + выбор сферы, выдача фильтруется под аудиторию |

| 3 | Инфа в удобном для аудитории формате | Карточки без воды: описание, вилка зарплаты, 3 конкретных первых шага |
| 4 | Доступ к пополняемой БД + описание формата | SQLite-таблица `careers`, формат описан ниже |

**Этапы:**
1. ✅ Каркас бота: `/start`, главное меню, обработчики кнопок.
2. ✅ FSM — ведём пользователя по шагам (трек → сфера → результат).
3. ✅ База данных: создание таблицы, стартовое наполнение, выборка.
4. ✅ Персонализация: выдача зависит от трека.
5. ⬜ Дальше можно: кнопка «ещё профессии», поиск по навыку, сохранение избранного.

## 🗃 Структура БД и как её пополнять

Вся инфа по профессиям — в таблице `careers`. Таблица и стартовые данные создаются сами при первом запуске.

### Поля таблицы `careers`:
| Поле | Тип | Что хранит |
|------|-----|------------|
| `id` | INTEGER | ID профессии (сам по себе) |
| `title` | TEXT | Название профессии |
| `category` | TEXT | Сфера: `IT`, `Design`, `Management` |
| `target_audience` | TEXT | Для кого: `teen`, `adult` или `all` |
| `description` | TEXT | Краткое описание (1-2 предложения) |
| `skills_required` | TEXT | Нужные навыки / стек |
| `avg_salary` | TEXT | Вилка зарплаты |
| `first_steps` | TEXT | 3 первых шага (через `\n`) |

> **Для заказчика:** чтобы добавить профессию, достаточно одной строки в таблицу.
> Главное — правильно указать `category` (по ней бот группирует) и `target_audience`
> (`teen` — покажется подросткам, `adult` — свитчерам, `all` — всем).

### Пример добавления профессии:
```sql
INSERT INTO careers (title, category, target_audience, description, skills_required, avg_salary, first_steps)
VALUES (
    'Python-разработчик',
    'IT',
    'all',
    'Пишет бэкенд для сайтов, ботов и сервисов.',
    'Python, Git, SQL',
    'от 80 000 ₽',
    '1. Выучить синтаксис Python\n2. Написать Telegram-бота\n3. Освоить Git и GitHub'
);
```

### Что можно добавить в БД дальше (рекомендации заказчику):
* Новые сферы: `Marketing`, `Finance`, `Medicine`.
* Поле `growth` — перспективы и карьерный рост.
* Поле `link` — ссылка на курс или статью по профессии.
